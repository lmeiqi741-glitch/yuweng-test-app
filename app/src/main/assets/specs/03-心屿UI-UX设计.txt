ㅤㅤ 1. 设计理念与原则

ㅤㅤㅤ 1.1 核心设计哲学

ㅤㅤㅤㅤ 「慢、轻、真、柔」四字真言

```
慢（Slow）：所有节奏都慢下来，动画 0.8-1.5 秒
轻（Light）：视觉轻量，留白 > 60%
真（Real）：真实数据驱动，拒绝虚假繁荣
柔（Soft）：柔化所有边角，柔化所有交互
```

ㅤㅤㅤ 1.2 五大设计原则

| 原则 | 说明 | 反例 |
|------|------|------|
| ㅤㅤ零压力ㅤㅤ | 永远只有"可以"，没有"必须" | ❌ 强制每日任务、限时活动 |
| ㅤㅤ慢节奏ㅤㅤ | 动画慢、过渡柔、不催促 | ❌ 倒计时、进度条压力 |
| ㅤㅤ柔交互ㅤㅤ | 大按钮、宽间距、高容错 | ❌ 小按钮、密集布局 |
| ㅤㅤ少文字ㅤㅤ | 用图像传达，留白即美 | ❌ 长篇弹窗、红点提醒 |
| ㅤㅤ沉浸感ㅤㅤ | 全屏沉浸，少 UI 元素 | ❌ 顶部 Banner、底部 Tab 杂乱 |

ㅤㅤㅤ 1.3 三大反直觉设计

ㅤㅤㅤㅤ ❌ 我们坚决不做

```
❌ 任何形式的红点未读提示
❌ 任何"限时""倒计时""错过可惜"
❌ 任何排行榜、等级、战力显示
❌ 任何带紧迫感的文案（"立即""马上""立刻"）
❌ 任何比较机制（"你比 XX% 用户..."）
❌ 任何能制造焦虑的视觉元素
```

ㅤㅤㅤㅤ ✅ 我们坚持做

```
✅ 永远只说"可以"，不说"应该"
✅ 永远展示"已经拥有的"，不展示"缺失的"
✅ 永远用柔和的圆角，从不用尖锐形状
✅ 永远用慢节奏，从不催促
✅ 永远给"不做"的自由
```

ㅤㅤㅤ 2.2 字体系统

ㅤㅤㅤㅤ 字体选择

```
中文：思源宋体（Noto Serif SC）   - 标题
中文：思源黑体（Noto Sans SC）   - 正文
英文：Cormorant Garamond         - 标题
英文：Inter                      - 正文
数字：SF Pro Display / Roboto    - 数字显示
```

ㅤㅤㅤㅤ 字号体系

```
Display   32px  ─── 页面大标题
H1        24px  ─── 一级标题
H2        20px  ─── 二级标题
H3        18px  ─── 三级标题
Body      16px  ─── 正文（默认）
Caption   14px  ─── 辅助说明
Micro     12px  ─── 极小说明
```

ㅤㅤㅤㅤ 字重

```
Light      300  ─── 大段抒情文字
Regular    400  ─── 默认正文
Medium     500  ─── 强调文字
Semibold   600  ─── 标题
Bold       700  ─── 重要数字
```

ㅤㅤㅤㅤ 行高与字间距

```
行高：1.6-1.8（抒情文字 1.8，普通 1.6）
字间距：0.02em-0.05em
段间距：1.5em
```

ㅤㅤㅤ 2.3 间距系统

```
基础单位：4px

间距梯度：
4px    - 极紧凑
8px    - 紧凑
12px   - 默认
16px   - 标准
24px   - 舒适
32px   - 宽松
48px   - 大量留白
64px   - 视觉呼吸
```

ㅤㅤ重要原则ㅤㅤ：
- ⚠️ 移动端最小触摸目标 48×48dp
- ⚠️ 按钮内边距最小 16px
- ⚠️ 卡片之间最小 16px

ㅤㅤㅤ 2.4 圆角系统

```
小圆角   8px   ─── 标签、小图标
中圆角   16px  ─── 卡片、按钮
大圆角   24px  ─── 大卡片、对话框
超大圆角 32px  ─── 弹窗、主面板
胶囊     999px ─── 状态标签
```

ㅤㅤ重要原则ㅤㅤ：
- ⚠️ 永远使用圆角，从不用尖角
- ⚠️ 圆角半径 ≥ 元素高度的 25%

ㅤㅤㅤ 2.5 阴影系统

```
微阴影   0 2px 8px rgba(0,0,0,0.04)    ─── 卡片
轻阴影   0 4px 16px rgba(0,0,0,0.06)   ─── 浮动元素
中阴影   0 8px 24px rgba(0,0,0,0.08)   ─── 弹窗
深阴影   0 16px 32px rgba(0,0,0,0.10)  ─── 模态框
```

ㅤㅤ重要原则ㅤㅤ：
- ⚠️ 阴影颜色永远带轻微的暖色调
- ⚠️ 阴影模糊半径 ≥ 偏移量 × 2

ㅤㅤ 4. 核心用户流程

ㅤㅤㅤ 4.1 新用户首次启动流程

```
启动 App
   ↓
【启动页】Logo + 慢动画（2 秒）
   ↓
【引导页 1】"在这个快节奏的世界里..."
   - 文字逐字显现，配钢琴曲
   ↓
【引导页 2】"每个人都需要一个角落..."
   - 渐变背景过渡
   ↓
【引导页 3】"不是为了逃避，而是为了回来。"
   ↓
【创建岛屿】
   - 输入岛屿名称
   - 选择初始区域（默认光之森林）
   ↓
【选择第一个 AI 角色】
   - 屿翁欢迎（首次对话）
   ↓
【第一次签到】
   - "今天，你感觉如何？"
   ↓
【岛屿首次生成】
   - AI 根据情绪生成初始岛屿
   - 3D 渲染飞行镜头
   ↓
【进入主岛】
```

ㅤㅤㅤ 4.2 每日使用流程

```
打开 App
   ↓
【启动 → 主岛】
- 岛屿根据上次情绪自动渲染
- 上次离开时停留的视角
   ↓
【签到提示】（如今日未签到）
- 主岛中心出现柔和光晕
- "你今天感觉如何？"
   ↓
【签到完成】
- 岛屿氛围实时变化
- AI 旁白："今天的风，有点温柔。"
   ↓
【自由探索】
- 漫步 / 种记忆 / 写信 / 访友 / 与 AI 对话
- 任何时候都可退出，无惩罚
```

ㅤㅤㅤ 4.3 记忆种植流程

```
进入"记忆种植"
   ↓
【选择类型】
- 拍照 / 录音 / 写字 / 画画 / 走路 / 听歌
   ↓
【输入内容】
- 拍摄 / 录制 / 输入 / 绘画
   ↓
【添加情绪】
- 自动识别 + 手动确认
   ↓
【选择区域】
- 4 个区域之一（推荐）
- 或自定义位置
   ↓
【预览生成】
- AI 生成预览效果
- "这将变成一棵树，象征这天的阳光。"
   ↓
【确认种植】
- 慢动画：种子 → 发芽 → 生长
- 配乐：自然音 + 柔和旋律
   ↓
【完成】
- 显示在岛屿上
- AI 旁白："这颗种子会陪你很久。"
```

ㅤㅤㅤ 4.4 跨岛陪伴流程

```
打开 App → 看到朋友列表
   ↓
【朋友状态】（仅氛围，不显示数据）
- 🌸 朋友 A 的岛：阳光明媚

   ↓

- 系统温柔提示："感谢你的陪伴。"
- 不强制后续互动

│                                     │
│      （岛屿 3D 渲染）                 │
│                                     │
│                                     │
│                                     │
│                  ┌──────┐           │

ㅤㅤㅤㅤ 详细说明

ㅤㅤ顶部状态栏ㅤㅤ：
- 显示真实时间（24 小时制）
- 显示岛屿整体氛围图标（🌸/☁️/🌧️/⭐）
- 显示温度（可选）
- 字色：黛灰 50% 透明

ㅤㅤ主视觉区（占 70%）ㅤㅤ：
- 岛屿 3D 实时渲染
- 跟随时间变化（早晨/中午/傍晚/夜晚）
- 跟随情绪变化（4 种氛围）
- 镜头跟随缓慢自动移动（呼吸感）
- 支持双指缩放、单指拖拽

ㅤㅤ签到入口（浮动按钮）ㅤㅤ：
- 圆形按钮，半径 64px
- 暖阳金背景 + 月光白图标
- 柔和阴影
- 文字提示"今日心屿 +1"（无未读感）

ㅤㅤㅤ 6.1 反焦虑交互设计

| 场景 | 普通做法 | 我们做法 |
|------|---------|---------|
| 签到提示 | 弹窗 + 红点 | 主岛柔和光晕，无文字提示 |
| 未签到提醒 | Push + 角标 | 不主动推送 |
| 朋友消息 | 红点 + 数字 | 仅在朋友列表显示氛围图标 |
| 写信到期 | 红色提醒 | 主页柔和光晕，无文字 |
| 年度电影发布 | Push 弹窗 | 节日礼物形式（圣诞前夜） |
| 邀请好友 | 强制分享 | 隐藏在设置中 |

ㅤㅤ 7. 动效规范

ㅤㅤㅤ 7.1 动效原则

```
1. 慢：所有动效时长 ≥ 300ms
2. 柔：使用 ease-out / ease-in-out，禁止 linear
3. 自然：模拟自然物理（重力、阻尼、弹性）
4. 一致：相同操作使用相同动效
5. 克制：永远不要"炫技"
```

ㅤㅤㅤ 7.2 标准动效时长

```
即时反馈：100-200ms    （按钮按下、勾选）
元素过渡：300-500ms    （颜色变化、显隐）
页面切换：400-600ms    （左右滑动、淡入淡出）
复杂动画：800-1500ms   （签到完成、记忆种植）
特别仪式：2000-3000ms  （首次登录、年度电影）
```

ㅤㅤㅤ 7.3 缓动函数

```
ease-out：cubic-bezier(0.0, 0.0, 0.2, 1)       元素进入
ease-in：cubic-bezier(0.4, 0.0, 1, 1)          元素退出
ease-in-out：cubic-bezier(0.4, 0.0, 0.2, 1)    状态切换
spring：cubic-bezier(0.34, 1.56, 0.64, 1)      弹性效果
```

ㅤㅤㅤ 7.4 关键动效示例

ㅤㅤㅤㅤ 签到完成动效
```
0.0s   用户点击"让岛屿听见"
0.3s   按钮缩放反馈
0.5s   整个屏幕缓慢淡出
0.8s   岛屿环境开始变化（颜色、光照、粒子）
1.5s   AI 旁白开始
2.0s   主岛完全呈现新氛围
3.0s   镜头缓慢拉远，显示整个岛屿
3.5s   UI 渐入
4.0s   完成
```

ㅤㅤㅤㅤ 记忆种植动效
```
0.0s   用户确认位置
0.3s   相机视角切换到种植点
0.8s   种子缓缓落下（重力感）
1.5s   种子入土（轻微震动反馈）
2.0s   缓慢发芽
2.5s   生长动画（曲线自然）
3.0s   完全成熟
3.5s   周围环境轻微反应（鸟飞过、光线变化）
4.0s   完成
```

ㅤㅤ 9. 无障碍设计

ㅤㅤㅤ 9.1 视觉无障碍

```
- 所有文字与背景对比度 ≥ 4.5:1（WCAG AA）
- 大文字（18px+）对比度 ≥ 3:1
- 不仅依赖颜色传达信息（图标 + 文字）
- 焦点状态清晰可见
- 字号支持动态调整（标准/大/特大）
```

ㅤㅤㅤ 9.2 触控无障碍

```
- 最小可点击区域 48×48dp
- 按钮间距 ≥ 8px
- 支持手势替代（长按 = 双击）
- 滑动操作可被点击替代
- 重要操作可被语音替代
```

ㅤㅤㅤ 9.3 认知无障碍

```
- 永远不用专业术语
- 文案简洁（一句话能说清的不用两句）
- 永远给出明确下一步
- 永远给"返回"路径
- 错误信息永远友好
```

ㅤㅤㅤ 9.4 辅助技术支持

```
- VoiceOver / TalkBack 支持
- 动态字体缩放支持
- 高对比度模式支持
- 减少动效选项（系统级）
- 字幕支持（所有音频内容）
```

ㅤㅤㅤ 9.5 情感无障碍

```
- 提供"我现在无法签到"按钮（不惩罚）
- 提供"暂停通知"选项
- 提供"度假模式"（7 天不提醒）
- 提供"轻度使用"模式（自动简化）
```

ㅤㅤ 13. 设计哲学总结

ㅤㅤㅤ 13.1 三个"永远"

```
永远慢：所有节奏都比用户预期的慢一点点
永远柔：所有交互都比用户预期的温柔一点点
永远真：所有反馈都比用户预期的真实一点点
```

ㅤㅤㅤ 13.2 三个"绝不"

```
绝不催促：从不制造时间压力
绝不比较：从不展示他人数据
绝不打扰：从不主动推送通知
